# Perplexity OpenCode Gateway (Chrome Extension)

Автономное расширение Chrome (Manifest V3), выступающее в роли API-шлюза к сервису [https://www.perplexity.ai](https://www.perplexity.ai) для интеграции с **OpenCode** и любыми локальными агентными системами.

---

### Архитектурные особенности браузера и реализация

В соответствии с моделью безопасности браузера Google Chrome (Manifest V3):
* Браузерным расширениям **запрещено** напрямую открывать слушающие TCP серверные сокеты (`server.listen()`) внутри песочницы Service Worker из соображений безопасности.
* Поэтому архитектура шлюза реализована максимально автономно и гибко:
  1. **Chrome Extension (MV3)**: Встраивается в страницу Perplexity (`content.js`), перехватывает и выполняет запросы, следит за сессией, авторизацией и ведет строгий учет лимитов (в час и в сутки).
  2. **Zero-dependency Local Relay (`relay.js`)**: Компактный скрипт на стандартной библиотеке Node.js (без установки npm-пакетов), который поднимает порт `127.0.0.1:8085` и предоставляет стандартный **OpenAI-совместимый эндпоинт** (`POST http://127.0.0.1:8085/v1/chat/completions`).
  3. Расширение в фоновом режиме опрашивает очередь запросов (`/poll`), направляет запрос во вкладку Perplexity, считывает сгенерированный ответ и возвращает результат агенту OpenCode.

### Возможности

* 🤖 **Полная эмуляция OpenAI API**: агент OpenCode может обращаться к `http://127.0.0.1:8085/v1` так же, как к официальному OpenAI API (`/chat/completions`).
* 📊 **Контроль и отслеживание лимитов**:
  * Лимит запросов в час (настраиваемый).
  * Лимит запросов в сутки (настраиваемый).
  * Прогресс-бары и индикация в UI расширения.
  * Автоматический сброс счетчиков по таймерам.
* 🌐 **Автономность**:
  * Автоматическое обнаружение или открытие фоновой вкладки `perplexity.ai`.
  * Проверка статуса авторизации и готовности вкладки.
  * Защита от зависаний (таймаут ответа).
* 🖥️ **Удобный Popup интерфейс**:
  * Статус подключения к OpenCode Relay.
  * Текущие лимиты и расход запросов.
  * Форма ручной отправки тестового запроса и предпросмотр ответа.
  * Кнопка быстрого перехода в Perplexity.

### Установка и запуск

#### 1. Установка расширения в Chrome
1. Откройте Chrome и перейдите по адресу: `chrome://extensions/`
2. В правом верхнем углу включите **«Режим разработчика»** (Developer mode).
3. Нажмите **«Загрузить распакованное расширение»** (Load unpacked).
4. Выберите папку `extensions/perplexity-opencode-gateway`.

#### 2. Запуск локального шлюза на 127.0.0.1:8085
В терминале выполните:
```bash
node extensions/perplexity-opencode-gateway/relay.js
```
Шлюз запустится на `http://127.0.0.1:8085`.

#### 3. Настройка OpenCode
В конфигурации вашего агента OpenCode укажите:
* **Base URL / API Endpoint**: `http://127.0.0.1:8085/v1`
* **API Key**: `perplexity-gateway` (или любой произвольный текст)
* **Model**: `perplexity-web` (или `default`)

### Структура файлов расширения
* `manifest.json` — Манифест Chrome расширения (Manifest V3, разрешения, хосты).
* `background.js` — Фоновый сервис-воркер: поллинг локального порта, учет лимитов, координация с Perplexity.
* `content.js` — Скрипт страницы Perplexity: ввод промпта, отправка, мониторинг генерации ответа.
* `popup.html` / `popup.js` — Интерфейс панели управления и мониторинга квот.
* `relay.js` — Легковесный автономный HTTP/OpenAI релей для привязки к `127.0.0.1:8085`.
